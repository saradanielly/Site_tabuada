🧮site tabuada

  Um projeto desenvolvido para praticar HTML, CSS e JavaScript, permitindo ao usuário gerar a tabuada de qualquer número de forma simples, rápida e interativa. <br>

📖sobre o projeto <br>

  Após assistir algumas aulas do professor Gustavo Guanabara decidi criar este site. Ele nos deu um desafio, criar um projeto com as funçoes que ele
mesmo usou para criar um projeto de exemplo, a partir disso decidi criar esse site. <br>
